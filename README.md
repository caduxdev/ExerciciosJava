# ☕ Jornada Java: De Estudante a Programador

Este repositório é o meu diário de bordo na trilha de aprendizado da linguagem **Java**. Aqui deposito todos os exercícios, desafios de lógica e pequenos projetos que desenvolvo enquanto construo minha base para me tornar um desenvolvedor Java profissional.

## 🎯 Objetivo
O foco principal é dominar o ecossistema Java, desde a sintaxe básica até frameworks modernos (Spring Boot), passando por boas práticas de programação, Estrutura de Dados e Programação Orientada a Objetos (POO).

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
*   **Linguagem:** Java 25
*   **IDE:** IntelliJ IDEA (macOS)
*   **Versionamento:** Git & GitHub
